#+TITLE: From one easystack line to a build set
#+OPTIONS: toc:t num:nil

~eb-stack pr-overlap~ turns each easystack line a pull request adds into the
modules that line would build on the installed stack. This page follows open
EESSI software-layer pull requests 1759, 1728, and 1787 for 2026.06, against
~/cvmfs/software.eessi.io~ ~x86_64/amd/zen4~, using the easyconfigs shipped
with EasyBuild 5.4.0. The command writes records. It does not build.

The commands that produce the same files are in
[[file:../howto/pr-overlap.org][find shared builds across open pull requests]].
The record fields are in [[file:../reference/formats.org][output formats]].

* Closure

~lfbf-2026.1.eb~ is a toolchain recipe. The fields the closure reads are:

#+begin_src text
toolchain = SYSTEM

local_llvmver = '21.1.8'

dependencies = [
    ('llvm-compilers', local_llvmver),
    ('FlexiBLAS', '3.5.0', '', ('llvm-compilers', local_llvmver)),
    ('FFTW', '3.3.10', '', ('llvm-compilers', local_llvmver)),

#+end_src

The recipe assigns no ~builddependencies~. An installed module is a leaf, so
the walk records these three dependencies and does not open them. The module
names in the record are:

#+begin_src text
lfbf/2026.1                                          to build
├── llvm-compilers/21.1.8                            installed
├── FlexiBLAS/3.5.0-llvm-compilers-21.1.8            installed

└── FFTW/3.3.10-llvm-compilers-21.1.8                installed
      toolchain: llvm-compilers/21.1.8
#+end_src

~lfbf~ itself uses the system toolchain, which is omitted from the module
name. ~FlexiBLAS~ and ~FFTW~ pin ~llvm-compilers~ 21.1.8, which is the
installed ~llvm-compilers/21.1.8~ module.
