#+TITLE: Dependency closure
#+OPTIONS: toc:t num:nil author:nil

A dependency closure lists every module one change reaches. The change
may be an easyconfig, an easyblock, or one bundled component. A software
bill of materials (SBOM) records the components and the edges. The record
is planned: the recipes supply it before anything is installed.

An easyconfig author reads the closure of one recipe bump. A reviewer
compares pull requests that share a file or a module. An easyblock author
lists the recipes that name a changed class. A framework author lists
those recipes. Triage lists the installed modules that carry one component
from a Common Vulnerabilities and Exposures (CVE) entry. A software-layer
maintainer lists the pull requests that would build one module. A site
maintainer lists the installed modules an upstream pull request changes.
The annual toolchain bump is the generation step in the first section. A
security or compliance reader consumes the CycloneDX document. A
conda-forge porter reads the planned SBOM from ~package inspect~. A Spack
porter reads that document too.

The runs below use recorded slices of upstream trees.
~tests/sbom_recorded/cbc~, ~tests/sbom_recorded/gromacs~,
~tests/sbom_recorded/quarto~, and ~tests/sbom_recorded/rebuild~ are byte
copies of easybuild-easyconfigs ~develop~ at
~981d2123dddccca9ce0b15f9eb2643e872332f5e~, the commit
~scripts/fetch-upstream-trees.sh~ creates a checkout of. The easyconfigs under
~tests/pr_overlap_layer~ are the same kind of copy. ~prs.json~ there is
the recorded pull-request file for software-layer pull requests 1585 and 1728.
~tests/sbom_recorded/easyblock~ is a byte copy of the v5.4.1 easyblocks,
framework, and easyconfigs tags that script pins.
~tests/sbom_recorded/foreign~ is the conda-forge zlib feedstock recipe at
~e34000ac354055f133215d211048bc3289afe5f4~ and the Spack zlib ~package.py~
at ~a19611deab3c33e3b2855b8379e8ddee12ef843a~. Each directory keeps the
upstream licence file. ~tests/pr_overlap_easyconfigs_open~ is the recorded
open easybuild-easyconfigs pull requests.
~tests/component_reach_recorded~ is the cURL and git slice from the same
develop commit. The runs write under ~/tmp/sbom-demo~.

* The annual toolchain bump

A generation maintainer asks which packages change version together.
The recorded step is foss-2025a to foss-2025b for Cbc. The slice has the
foss-2025b closure of ~Cbc-2.10.12~ and the foss-2025a counterparts of
Cbc, Cgl, Clp, and MUMPS. ~stack solve --sbom-out~ writes a CycloneDX 1.5
document for the selection. ~stack sbom --lock~ writes the same document
later, from the lock. Both commands read edges and checksums from the
easyconfigs the lock names. A runtime dependency that is also selected is
a ~dependsOn~ edge. A builddependency is the component property
~eb_stack:buildDependsOn~. The document does not draw an edge from every
package to every other package.

~--build-list-out~ writes the easyconfigs to build.
~--jenkins-roots-only~ writes one Jenkins line for the policy root and
leaves the dependencies to ~eb --robot~.
