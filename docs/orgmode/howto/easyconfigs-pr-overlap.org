#+TITLE: Close open easybuild-easyconfigs pull requests
#+OPTIONS: toc:t num:nil author:nil

Goal: for each open pull request on easybuild-easyconfigs, name the
easyconfigs it adds or changes, the dependency closure of those files
against a pinned develop tree, and the modules it shares with the other
open pull requests.

The file text is data. Nothing from a pull request is executed, and
nothing is posted back to the pull request.

* Read the pull requests over HTTPS

~fetch_open_easyconfig_prs~ GETs
~https://api.github.com/repos/<owner>/<name>/pulls?state=open~ and, for
each pull request, the changed-file list. Head text is
~https://raw.githubusercontent.com/<owner>/<name>/<sha>/<path>~. Base
text is the same URL with the base ref (~develop~ unless another ref is
set). A 404 on the base means the file was added. =GITHUB_TOKEN= or =GH_TOKEN= is sent to api.github.com when set.

The command the tool runs is ~eb-stack pr-overlap --kind easyconfigs --open OWNER/NAME~.
It calls ~fetch_open_easyconfig_prs~ and writes the
same records as ~--pr~. ~--base-ref~ is the base ref in the raw URL
(~develop~ when the flag is omitted). The ignored test
~live_github_open_easyconfigs_pull_request~ calls the same function
against ~easybuilders/easybuild-easyconfigs~, one list page, one pull
request, and one easyconfig file.

~examples/easyconfigs-pr-overlap/fetch-prs.sh~ is the clone-side collector.
It uses ~gh~ and git to write the same JSON, and it does not check a pull
request out. Use it when the inputs already come from a local clone. Use
~--open~ when the command should fetch the pull requests itself.

* Easyconfigs merge order

~--merge-order~ and ~--impact~ answer a different question: in which
order to merge open pull requests, and which other build sets one merge
changes. For an easyconfigs run the edges are the ~depends-on~ rows in
~overlap.toml~ from the same run. ~after~ lists the pull request that
adds the module, and ~resolves~ lists those modules. The software-layer
run is
[[file:pr-overlap.org][find shared builds across open pull requests]].
