#+TITLE: Installation
#+OPTIONS: toc:t num:nil author:nil

~eb-stack~ 0.7.3 is the crates.io package ~eb_stack~ and the GitHub
release ~v0.7.3~. The binary name is ~eb-stack~. A release archive is a prebuilt binary. Building from a checkout, or
~cargo install eb_stack --locked~, needs Rust 1.90 or newer: that floor is ~rust-version~ in
the root ~Cargo.toml~. ~rustup toolchain install stable~ provides a
new enough compiler.

After installation, the [[file:get-started.org][get started]] page runs
inspect, shard, and admit on the fixtures in a checkout. Contributor
builds are on the [[file:contributing.org][contributing]] page.

* Static Linux archive

The ~x86_64-unknown-linux-musl~ release archive contains a statically linked
x86-64 binary. It does not require the host's glibc, so one archive supports
hosts with different glibc releases. The GNU Linux archive remains available
for hosts whose glibc satisfies its linkage requirements.

#+begin_src bash
curl -fsSL -O https://github.com/stackhands/eb-stack/releases/download/v0.7.3/eb_stack-x86_64-unknown-linux-musl.tar.xz
curl -fsSL -O https://github.com/stackhands/eb-stack/releases/download/v0.7.3/eb_stack-x86_64-unknown-linux-musl.tar.xz.sha256
sha256sum -c eb_stack-x86_64-unknown-linux-musl.tar.xz.sha256
tar -xf eb_stack-x86_64-unknown-linux-musl.tar.xz
#+end_src

* Linux and macOS

The shell installer picks the archive for the host:

| Host | Archive |
|-
| Linux x86-64 | ~eb_stack-x86_64-unknown-linux-gnu.tar.xz~ |
| Linux aarch64 | ~eb_stack-aarch64-unknown-linux-gnu.tar.xz~ |
| macOS Apple silicon | ~eb_stack-aarch64-apple-darwin.tar.xz~ |
| macOS x86-64 | ~eb_stack-x86_64-apple-darwin.tar.xz~ |

#+begin_src bash
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/stackhands/eb-stack/releases/download/v0.7.3/eb_stack-installer.sh \
  | sh
eb-stack --version
#+end_src

The script prints ~downloading eb_stack 0.7.3~ and the target triple,
then ~installing to~ the Cargo bin directory (~$CARGO_HOME/bin~, or
~~/.cargo/bin~ when ~CARGO_HOME~ is unset), then ~everything's installed!~.
~eb-stack --version~ prints:

#+begin_example
eb-stack 0.7.3
#+end_example

Add that bin directory to ~PATH~ when it is absent from the shell's ~PATH~.

* Linux x86-64 archive

The checksum file from the release is a ~sha256sum~ line. The archive
contains ~eb-stack~, ~LICENSE~, ~README.md~, and ~CHANGELOG.md~.

#+begin_src bash
curl -fsSL -O https://github.com/stackhands/eb-stack/releases/download/v0.7.3/eb_stack-x86_64-unknown-linux-gnu.tar.xz
curl -fsSL -O https://github.com/stackhands/eb-stack/releases/download/v0.7.3/eb_stack-x86_64-unknown-linux-gnu.tar.xz.sha256
sha256sum -c eb_stack-x86_64-unknown-linux-gnu.tar.xz.sha256
tar -xJf eb_stack-x86_64-unknown-linux-gnu.tar.xz
./eb_stack-x86_64-unknown-linux-gnu/eb-stack --version
#+end_src

#+begin_example
eb_stack-x86_64-unknown-linux-gnu.tar.xz: OK
eb-stack 0.7.3
#+end_example

The checksum file records the SHA-256 of the archive for the selected release.

* Windows

The release archive is
~eb_stack-x86_64-pc-windows-msvc.zip~. It contains ~eb-stack.exe~,
~LICENSE~, ~README.md~, and ~CHANGELOG.md~. The PowerShell installer on
the same release is ~eb_stack-installer.ps1~; its help says it unpacks
the archive into ~$env:CARGO_HOME/bin~ (or ~$HOME/.cargo/bin~) and adds
that directory to the user ~Path~.

#+begin_src bash
curl -fsSL -o eb_stack-x86_64-pc-windows-msvc.zip \
  https://github.com/stackhands/eb-stack/releases/download/v0.7.3/eb_stack-x86_64-pc-windows-msvc.zip
unzip -l eb_stack-x86_64-pc-windows-msvc.zip
#+end_src

* crates.io

#+begin_src bash
cargo install eb_stack --locked
eb-stack --version
#+end_src

~cargo install~ builds the 0.7.3 crate. The resulting ~eb-stack --version~
prints ~eb-stack 0.7.3~, the same string as the GitHub release binary.
~cargo binstall~ is a separate program. Stock Cargo on this host
answers:

#+begin_src bash
cargo binstall
#+end_src

#+begin_example
error: no such command: `binstall`
#+end_example

* From a git checkout

#+begin_src bash
git clone https://github.com/stackhands/eb-stack.git
cd eb-stack
cargo build --locked --release
install -Dm755 target/release/eb-stack ~/.local/bin/eb-stack
eb-stack --version
#+end_src

A release build of this tree prints:

#+begin_example
eb-stack 0.7.3
#+end_example

~=~/.local/bin~ has to be on ~PATH~. The test suite is ~cargo test
--locked~, described on the [[file:contributing.org][contributing]] page.
