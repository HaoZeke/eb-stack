============
``eb-stack``
============

Version 0.7.3 is the crates.io package and the GitHub release. ``package plan`` and ``package bump`` establish *resolves*. ``campaign run`` establishes *builds* and *binary-verified*.

* Why

#+begin_export rst
.. figure:: images/claim-ladder.svg
   :alt: Claim ladder from inspect through resolves, builds, and binary-verified
   :align: center

   Claim ladder: package plan and package bump establish resolves. campaign run establishes builds and binary-verified.
#+end_export

  A site that rebuilds an EESSI or EasyBuild generation keeps the dependency
  lock, the EasyBuild run, and the checks after install as separate records.
  ~eb-stack~ names those records ~resolves~, ~builds~, and ~binary-verified~.
  ~package plan~ and ~package bump~ establish ~resolves~. ~campaign run~
  establishes the other two. The campaign JSON spells the third claim
  ~binary_verified~. Closure, generation, baseline, toolchain family, and
  reachability are in the [[file:reference/glossary.org][glossary]].

  The same plan feeds a Jenkins build list. ~stack shard~ splits the list
  into jobs that can run together, and ~stack admit~ exits 78 when the
  scratch inode quota cannot hold the next lane. That model is
  [[file:explanation/sharding-admission.org][Sharding and inode admission]].

  EasyBuild still performs the build and the install. ~eb-stack~ routes
  ~eb --robot~ through a configured target. The emitted SBOM is the planned
  inventory; binary verification is the campaign claim that runs after install.
  The dependency domain is EasyBuild's ~name~ / ~version~ / ~toolchain~ /
  ~dependencies~ shape. Preferences for a distribution or a site are inputs
  to [[https://github.com/mamba-org/resolvo][Resolvo]].

* Who it is for

  Site administrators building a stack start with
  [[file:install.org][Installation]] and [[file:get-started.org][Get started]],
  then the how-to guides in the sidebar (annual bump, new package, shard,
  campaign repair). The GitHub release is 0.7.3, with archives for Linux
  (x86-64, aarch64), macOS, and Windows. ~cargo install eb_stack --locked~
  builds that same 0.7.3 from crates.io. ~eb-stack --version~ prints
  ~eb-stack 0.7.3~.

  Contributors start at [[file:contributing.org][Contributing]]: Rust 1.90,
  ~cargo test --locked~, and the Org-to-Sphinx build. The generated Rust API
  is the [[file:reference/rust-api.org][Rust API]] page.
